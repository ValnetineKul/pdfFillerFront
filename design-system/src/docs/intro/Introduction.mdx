# Введение

Добро пожаловать в систему дизайна для продуктов U-платформы.
Если вы только начинаете работать с системой дизайна,
вот список рекомендованных ресурсов и руководств, которые помогут вам начать.

## Дизайн ресурсы

Дизайн-система имеет визуальное представление
компонентов с различными вариантами, стилями, палитрой, размерами, типографией и иконками...

## Ресурсы для разработки

Если вы только начали работу с системой дизайна, важно познакомиться с
ключевыми инструментами и процессами, которые используются в разработке
UI и будут необходимы в вашей работе.
Технически, дизайн-система основана на двух основополагающих библиотеках PandaCSS & React Aria Components (RAC), но есть и вспомогательные инструменты.
Вот несколько инструментов, с которыми вам придется столкнуться:

### React Aria Components

Это библиотека нестилизованных компонентов и хуков для React,
которая помогает создавать доступные, высококачественные компоненты пользовательского
интерфейса для приложений или дизайн-систем. Она предоставляет компоненты для общих
шаблонов пользовательского интерфейса с встроенными возможностями доступности,
интернационализации, взаимодействия и поведения. Это позволяет нам стилизовать
компоненты в уникальном дизайне и стиле, не разрабатывая эти сложные аспекты с нуля.
[Посетить сайт React Aria Components](https://react-spectrum.adobe.com/react-aria/getting-started.html)

### Panda CSS

Эта библиотека позволяет генерировать примитивы стилизации для создания атомарного CSS и рецептов
в типизированной и читаемой форме.
[Посетить сайт Panda CSS](https://panda-css.com/docs/overview/getting-startedl)

### Maskito

Используется для маскинга полей ввода в формах.
[Посетить сайт Maskito](https://maskito.dev/getting-started/what-is-maskito)

### @internationalized/date

Используется для работы с датами и календарями.
Позволяет форматировать значения дат для разных регионов в разных частях света.
[Посетить сайт @internationalized/date](https://react-spectrum.adobe.com/internationalized/date/index.html)
