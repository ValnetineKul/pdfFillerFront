## Основные составляющие дизайна

Наша система дизайна включает следующие ключевые элементы:

- **Цветовая палитра** — тщательно подобранные цвета, обеспечивающие визуальную гармонию и доступность.
- **Токены** — стандартизированные значения для создания согласованных интерфейсов.
- **Типографика** — шрифты и стили, обеспечивающие читаемость и эстетическую целостность на всех устройствах.
- **Иконки** — элемент графического интерфейса, небольшая картинка, обозначающая приложение, файл, каталог, окно, компонент операционной системы, устройство и т. п
- **Storybook** — инструмент для документирования и тестирования UI-компонентов в изолированной среде.
- **Figma** — для проектирования и прототипирования интерфейсов.

## Составляющие дизайна

### Цветовая палитра

Цветовая палитра включает основные и второстепенные цвета, которые используются в приложении:

- **Основные цвета**: Эти цвета применяются для брендинга и ключевых элементов, таких как акценты. Из них формируются семантические токены, которые используются для разработки компонентов.
- **Второстепенные цвета**: Наряду с основными цветами полезно иметь выбор вторичных цветов для использования в таких компонентах,
  как бэйджи, оповещения и лэйблы. Эти вторичные цвета должны использоваться редко или в качестве акцентов, в то время как основной цвет (цвета) должен иметь приоритет.

### Токены

Это многократно используемые значения — такие, как цвет заливки, подложка, видимость и другие,
которые можно повторно использовать во всех проектах.
Они помогают сэкономить время и усилия при создании сложных систем дизайна,
обеспечивая постоянство и управляемость значений дизайна.

```
├── core
│ ├── blurs.ts
│ ├── borderWidths.ts
│ ├── colors.ts
│ ├── index.ts
│ ├── radii.ts
│ ├── shadows.ts
│ ├── sizes.ts
│ ├── spacing.ts
│ └── typography.ts
```

[Ознакомиться с понятием токена в Figma](https://www.figma.com/design/M2aUMU5VEQEEYRyoEig9gE/%F0%9F%92%A5-Design-system-UPlatform?node-id=10444-74572&m=dev)

### Отступы

Отступы — это заранее определённые значения, которые помогают поддерживать единообразие в интервалах, отступах и скруглениях углов:

- **Система единиц**: Отступы основаны на модульной сетке с шагом 4 пикселя. [Узнать больше о системе единиц](/docs/foundation-8px-design--docs)
- **Последовательность**: Это помогает создавать сбалансированные и визуально гармоничные макеты.

### Типографика

Типографика включает шрифты, размеры и стили, используемые для текстовых элементов в приложении:

- **Размеры**: Применяется типографическая шкала для поддержания визуальной иерархии текстов.

- **Семейства шрифтов**:

  1. **Display** — используется для крупных заголовков, баннеров и специальных случаев по усмотрению дизайнера.
  2. **Default** — основное семейство шрифтов, используемое в большинстве элементов проекта.

[Посмотреть доступные значения размеров шрифта](/docs/system-typography--docs)

Отдельно можно менять значения жирности шрифта. `fontWeight: 'medium'`

```
 label: {
  textStyle: 'sm',
  fontWeight: 'medium',
  color: 'text.secondary',
}
```

Список допустимых значений:

```
normal: { value: '400' },
medium: { value: '500' },
semibold: { value: '600' },
bold: { value: '700' },
```

### Иконки

**Иконки в интерфейсе** — это небольшие графические символы, представляющие функции.
Замок означает блокировку, галочка — выполненное действие, корзина — удаление.
Иконки интуитивно понятны и широко используются, облегчая взаимодействие с интерфейсами.

В **DS** существует широкий набор иконок.
[Ознакомиться с полным списком иконок в Figma](https://www.figma.com/design/M2aUMU5VEQEEYRyoEig9gE/%F0%9F%92%A5-Design-system-UPlatform?node-id=798-7641&m=dev)

> На данный момент не все иконки доступны для использования. При необходимости надо добавлять иконки вручную.
> иконки подключаются из пакета `@front/icons` через компонент `Icon` и проп `name` (см. тип `IconName`).
