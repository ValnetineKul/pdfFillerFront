# Доступность

Создание инклюзивных приложений, доступных для всех, очень важно. **React Aria** помогает создавать доступные компоненты, обеспечивая поддержку экранных читателей и навигации с клавиатуры.

### Введение

**Доступность** — это возможность использования приложений всеми, включая людей с ограниченными возможностями. Это охватывает зрительные, слуховые, моторные и когнитивные нарушения. **React Aria** обеспечивает поддержку для людей с нарушениями зрения и моторики через экранные читатели и клавиатуру. Однако для других типов нарушений нужно учитывать дизайн.

Особенности доступности полезны и для людей без инвалидности. Например, опытные пользователи могут предпочитать навигацию с клавиатуры, что ускоряет работу с приложениями, особенно при вводе больших объемов данных.

### ARIA

**React Aria** реализует поддержку доступности по спецификации **WAI-ARIA** от W3C, которая описывает семантику для UI-контролов, чтобы технологии, такие как экранные читатели, могли корректно распознавать элементы. ARIA не предоставляет поведение, и разработчикам нужно реализовывать взаимодействия через JavaScript. **React Aria** упрощает этот процесс, предоставляя заранее настроенные семантические и поведенческие компоненты.

### Маркировка

Вы должны обеспечить текстовую метку для каждого элемента управления. Если метка не видна, используйте пропсы `aria-label` или `aria-labelledby`. **React Aria** предупредит в консоли, если метка отсутствует.

### Навигация с клавиатуры

**React Aria** реализует поддержку клавиатуры для всех компонентов, позволяя пользователям без мыши или сенсорного экрана легко перемещаться по приложению.

### Мобильные устройства

На мобильных устройствах пользователи экранных читателей взаимодействуют через жесты и виртуальный курсор. Для полной поддержки необходимо учитывать, что нет клавиатуры и стандартные сенсорные взаимодействия недоступны.

### Тестирование

Компоненты **React Aria** протестированы на различных устройствах и в разных браузерах, включая **macOS**, **Windows**, **iOS** и **Android**.
