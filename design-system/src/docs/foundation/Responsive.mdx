# Адаптивный дизайн

## Введение

Адаптивный дизайн — это фундаментальный аспект современной веб-разработки, который позволяет сайтам и приложениям беспрепятственно адаптироваться к разным размерам экранов и устройствам.

Panda предоставляет широкий набор адаптивных утилит и функций, облегчающих создание адаптивных макетов. Это достигается с помощью условных стилей для разных контрольных точек (breakpoints).

[Ознакомиться с Адаптивным дизайном от PandaCSS](https://panda-css.com/docs/concepts/responsive-design)

### MobileFirst

Это подход к разработке веб-дизайна и пользовательских интерфейсов, где проектирование начинается с наименьших экранов, таких как смартфоны, а затем масштабируется для больших экранов (планшеты, десктопы). Основные принципы:

1. **Приоритет мобильных устройств**: Дизайн и функциональность оптимизируются для мобильных устройств в первую очередь, а затем расширяются для большего экрана.
2. **Гибкость и адаптивность**: Макеты должны гибко подстраиваться под разные размеры экранов с помощью медиазапросов и адаптивных единиц измерения (например, rem, %).
3. **Простота и скорость**: Упрощенные элементы интерфейса и быстрая загрузка важны для улучшения опыта на мобильных устройствах с ограниченными ресурсами.
4. **Использование медиазапросов**: По мере увеличения размеров экрана добавляются дополнительные стили для улучшения пользовательского опыта на больших устройствах.

Этот подход гарантирует, что важный контент будет доступен и удобен на самых популярных устройствах — смартфонах, и улучшает масштабируемость на более крупные экраны.

> Пример применения:

```
{
  // mobile
  background: 'red.300',

  w640:{
  // tablet, desktop
    background: 'green.300',
  }
}
```

### Breakpoints

Ниже выписка с кастомизированными адаптивными точками которые применяются в проекте.

```
w320: '320px',
w375: '375px',
w480: '480px',
w560: '560px',
w640: '640px',
w768: '768px',
w940: '940px',
w1024: '1024px',
w1280: '1280px',
w1366: '1366px',
w1440: '1440px',
w1680: '1680px',
w1920: '1920px',
```

Возможности использования:

```
w560Down:{}, - от 560px и ниже
w560:{},- от 560px и выше
w560Only:{}, - от 560px и выше до следующей точки (640px)
w560ToW940:{}, - диапозон от 560px до 940px
```
